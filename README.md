# LockPC — bản phát hành / Releases

**LockPC** khóa thư mục và chặn ứng dụng trên Windows bằng một mật khẩu chính.
Không tài khoản, không Internet, không thu thập dữ liệu.

**LockPC** password-protects folders and blocks chosen apps on Windows with a
single master password. No account, no internet, no data collection.
